# 文档目录

毕业设计的过程材料统一归档在这里，建议按阶段分文件夹，文件名带日期便于追溯。

```
docs/
├── 01-开题/     任务书、开题报告、文献综述
├── 02-需求/     需求分析说明书、用例图
├── 03-设计/     概要设计、详细设计、数据库设计、UML 图
├── 04-测试/     测试计划、测试用例、测试报告
└── 05-论文/     论文各章节草稿、查重稿、终稿
```

## 几点建议

- **Word 文档也放进来**。版本管理能让你随时回退到"上周那一版"，比 `论文-最终版-真的最终版.docx` 靠谱得多。
- 图表源文件（drawio、Visio、PlantUML 文本）一并提交，后期改图成本会低很多。
- 论文终稿建议再导出 PDF 存一份，避免答辩现场因字体缺失导致排版错乱。
- 大体积附件（视频演示、数据集）不要进仓库，GitHub 单文件超 100MB 会被拒。
